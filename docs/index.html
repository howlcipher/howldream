The idea

What can induced failure teach us?

Traditional reliability work asks: how do we stop hallucination? HowlDream also asks what controlled failure can reveal about a system, and whether a speculative idea deserves investigation after challenge.

A strange answer is not a research result.

Experiments record an objective, hypothesis, baseline, condition, sources, outputs and measurements. Wrong ideas are experimental material. They never become trusted knowledge by being generated.

HowlCreate invents intentionally. HowlDream explores speculatively through measured experiments.

Reliability / Dreambench

Known failures. Grounded controls.

Unsupported claims

An answer asserts a fact absent from the supplied ledger.

False premises

A response accepts an assumption contradicted by known input.

Lost qualifiers

A transformed proposition changes “safe if tested” into “always safe.”

Conflicting evidence

An answer selects one side instead of recognizing incompatible records.

Invented sources

A fictional citation ID is absent from the supplied source set.

Numerical errors

A fixed arithmetic checker challenges a model's asserted result.

Dreambench has 14 authored fixtures: seven failures and seven controls. This is a regression suite for narrow checks, not a general hallucination detector. Benchmark scope

Evidence and reproducibility

Keep the experimental record.

Each run preserves its input snapshot, source and prompt hashes, candidate outputs, claims, checks, scores and report. New WAKE and replay runs retain lineage.

Mock output replay is deterministic. Real-provider replay repeats configuration; identical outputs are not guaranteed. Hosted private reasoning is never captured.

Authority boundary

Dreams can suggest. Dreams cannot authorize.

Dream output is data, not authority. No result deploys software, merges code, sends communications or approves actions. Supported means a named, limited check passed. Uncertainty stays visible.
