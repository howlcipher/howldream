Manual A family grouping: units 2/14 friction/workaround demand sensing; 3/18 cost/value
attribution; 4/12 downstream-change impact simulation; 8/17 agent traffic/safety controls;
other units separate. These are broad problem families, not duplicate mechanisms.
B grouping: 1/6 probabilistic release signals; 2/7 CI scheduling; 3/8 template lifecycle;
4/9 preview leases; 5/10 cache/image diagnostics. Human reviewer is this mission agent,
not blinded or independent. Definitions are inspectable in family-review-final.json.

A spans rationale archaeology, demand signals, waiting cost, downstream impact,
template curation, onboarding, ownership drift, agent governance, communication,
environment resource budgets, change-outcome learning, runtime drift and runbook testing.
B largely develops the supplied operational topics. No empirical benefit or novelty
superiority is inferred. All generated assertions remain UNVERIFIED.

Initial smoke inherited ambient Claude instructions and old lexical analysis missed
obvious repeats. Retained as diagnostic evidence, not the final comparison. Final smoke
uses safe-mode, neutral cwd and explicit neutral system prompt. The first phrase-link
revision over-grouped "Unconventional alternative" and late generic environment/dependency
mentions; negative controls now prevent those examples. Final v3 metrics are an offline
WAKE descendant of immutable remote outputs, not a new provider run or rewritten evidence.
Even v3 is an uncalibrated lexical/phrase proxy and can miss or over-group paraphrases.

Diversity continuation is optional and explicit: compact labels, rejected/explored areas,
and prior clusters can enter explored_families. Later generation prompts request different
families; no full candidate texts or ledger are injected. Baselines retain only externally
supplied family memory. Fixtures verify the prompt treatment, not a guaranteed model result.

Advisory selections: rationale archaeology (A unit 1) merits investigation only after its
source's tradeoff concern is reviewed; the actual direct-handoff demonstration selects
change-intent learning (A unit 11) from a non-rejected source. No product is built.
