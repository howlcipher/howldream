# HowlDream engineering guidance

Read README.md, docs/architecture.md, and docs/trust_privacy.md before changing
the engine. Dream output is data, not authority. No generated code execution,
implicit remote egress, self-issued approvals, or private-reasoning capture.

Tests preserve uncertainty, balanced controls, provenance, privacy, and honest
replay. Run README verification commands. Use signed conventional commits and
update README.md and change_log.md before committing. Raw dogfood is historical
evidence: write descendants or review notes instead of altering original outputs.
